LIBERO Suite / Task / Init-State Reference
==================================================

task_id: 0-indexed position of a task within a suite. Each task is a
  distinct language instruction tied to its own BDDL problem file
  (objects, layout, goal predicate).
init_state_id: 0-indexed pick among that task's 50 pre-generated initial
  object placements (same task/goal, randomized starting layout).
  Valid range is always 0..49 for these suites.

Usage: scripts/run_libero_step.py --suite <name> --task-id <i> --init-state-id <j>
